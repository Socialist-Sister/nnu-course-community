# 版本记录

## 0.1.0 · 2026-10-13

整理此前已上线的改动，并补齐维护工具。

- 评价支持“有帮助”、教师与学期筛选、排序；账号内可查看处理通知。
- 被下架评价可修改后申请复核，也可说明原文无需修改的理由。审核结果与通知、操作记录同步保存。
- 管理员可认领举报、留下内部备注，按内容审核和课程维护分工；后台提供操作手册。
- 添加范围有限的辱骂等内容检查，保留正常负面评价；更新页面说明、字标与透明图标。
- 发布前检查构建和备份，保留旧版静态资源；失败自动回退代码，并提供手动回退。
- 本地备份增加可移植加密副本和独立恢复工具；原 Windows 账号加密备份继续保留。
- 更新有安全公告的依赖至兼容版本，包括 Vite、Nodemailer、Sharp 及其相关构建依赖。更新锁文件，不跨主要版本迁移框架。

代码仓库不包含线上用户数据、备份、邮件密码或 SSH 私钥。此版本记录不代表这些资料已由协作者取得，也不表示已完成整台虚拟机的灾难恢复。
